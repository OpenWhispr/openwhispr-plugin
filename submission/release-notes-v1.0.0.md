# OpenWhispr v1.0.0

Initial OpenAI directory submission of OpenWhispr v1.0.0. Reuses the existing remote MCP server and six shipped skills for meeting recaps, note search, dictionary words, snippets, weekly reviews and recording transcription. Skill instructions work across assistants, with local transcription available only when the host can access the user's terminal and audio files. Adds OpenAI listing and review metadata; retains Claude compatibility.

This is a draft submission, not an announcement of availability.
